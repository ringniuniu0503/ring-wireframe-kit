<DocSection title="Overview">
  <h3 className="rwk-text-h3">When to use</h3>
  <ul className="rwk-text-body-default">
    <li>To reinforce a label or action with a recognizable symbol, such as in navigation tabs, buttons and list items.</li>
    <li>To save space where the meaning is widely understood, such as search, close or back.</li>
  </ul>

  <h3 className="rwk-text-h3">When not to use</h3>
  <ul className="rwk-text-body-default">
    <li>As the only carrier of important meaning. Pair the icon with a text label, or use text alone.</li>
    <li>As decoration that adds noise without helping recognition. Leave it out.</li>
    <li>For illustrations, photos or logos. Use Image instead.</li>
  </ul>

  <h3 className="rwk-text-h3">Sizes</h3>
  <ul className="rwk-text-body-default">
    <li><strong>xs</strong> — inline with Body/Default or Caption text, in dense lists, chips and badges.</li>
    <li><strong>s</strong> — next to Body/Large text and inside input fields.</li>
    <li><strong>m</strong> — standalone actions such as icon buttons and navigation bars.</li>
    <li><strong>l</strong> — moments of emphasis, such as empty states and feature highlights.</li>
  </ul>
  <Canvas of={IconStories.Sizes} />

  <h3 className="rwk-text-h3">Exceptions and notes</h3>
  <ul className="rwk-text-body-default">
    <li>Set color on the parent, not the icon. The icon always follows the surrounding text color.</li>
    <li>An icon is not interactive by itself. To make it tappable, place it in a button that meets the touch target size.</li>
    <li>Placeholder phase: the icon currently renders as an outlined box with its name on hover. The real glyphs will replace it without changing how the component is used.</li>
  </ul>
  <Canvas of={IconStories.InheritsTextColor} />

  <h3 className="rwk-text-h3">Iconography</h3>
  <ul className="rwk-text-body-default">
    <li>All icons come from <a className="rwk-doc-link" href="https://fonts.google.com/icons?icon.style=Rounded" target="_blank" rel="noreferrer">Material Symbols Rounded</a>. Do not add other icon sets.</li>
    <li>Pass the icon name exactly as listed there, in lowercase with underscores, for example <code>search</code>, <code>arrow_back</code> or <code>settings</code>.</li>
    <li>Style settings match Figma: weight 400, fill 0, grade 0.</li>
  </ul>

<DocSection title="Accessibility">
  <ul className="rwk-text-body-default">
    <li><strong>Decorative icons</strong> (no <code>label</code>) are hidden from screen readers with <code>aria-hidden</code>. Use this when nearby text already says the same thing.</li>
    <li><strong>Meaningful icons</strong> need a <code>label</code>. The icon is then announced as an image with that name.</li>
    <li><strong>Icon-only buttons</strong>: give the accessible name to the button, and leave the icon inside without a label so it is not announced twice.</li>
    <li><strong>Contrast</strong>: the icon uses the surrounding text color, so it meets the same contrast as that text.</li>
    <li><strong>Focus</strong>: the icon is never focusable on its own; keyboard focus belongs to the control that contains it.</li>
  </ul>
